# 7Flows Studio Landing Page Tests

Повний набір тестів для лендінгу студії 7Flows з замірами продуктивності та функціональними тестами.

## 🚀 Швидкий запуск

```bash
# Запуск всіх тестів
npm run test

# Запуск тільки лендінг тестів
npm run test:landing

# Запуск з UI режимом
npm run test:ui

# Запуск тільки performance тестів
npm run test:perf

# Запуск в конкретному браузері
npm run test:chromium
npm run test:firefox
npm run test:webkit
```

## 📊 Що тестується

### 🔧 Функціональні тести
- ✅ Навігація по секціях

5. **Services** - послуги
6. **Purpose** - мета компанії
7. **Reviews** - відгуки клієнтів
8. **FAQ** - відповіді на запитання

### 📱 Адаптивність
- Desktop (1440px+)
- Tablet (768px - 1439px)
- Mobile (320px - 767px)

## 🎨 Клас LandingPageTester

Основний клас для тестування лендінгу з методами:

- `navigateToPage(locale)` - навігація до сторінки
- `measurePerformance()` - замір метрик продуктивності
- `checkHeaderElements()` - перевірка елементів хедера
- `checkFooterElements()` - перевірка елементів футера
- `testSections(sections)` - тестування секцій
- `testNavigation()` - тестування навігації
- `testLocaleSwitcher()` - тестування перемикача мов
- `testResponsiveDesign()` - тестування адаптивності
- `generateReport(metrics, sections)` - генерація звіту

## 📊 Звіт тестування

Після запуску тестів генерується детальний звіт з:

## 🚨 Troubleshooting

### Проблеми з продуктивністю
- Перевірте з'єднання з інтернетом
- Очистіть кеш браузера
- Запустіть тести в headless режимі

### Проблеми з елементами
- **Селектори оновлені** - тепер використовують CSS класи замість data-testid
- Компоненти використовують CSS Modules, тому селектори шукають `[class*="componentName"]`
- Якщо тести не знаходять елементи - перевірте CSS класи в компонентах

### DevProfiler проблема
- `DevProfiler` використовує React Profiler - в продакшені немає HTML атрибутів
- **Виправлено**: селектори тепер шукають фактичні CSS класи компонентів

### Проблеми з локалізацією
- Перевірте наявність перекладів у `messages/*.json`
- Перевірте налаштування i18n routing

### Швидка перевірка без Playwright
```bash
npm run test:quick  # Перевіряє базову функціональність HTTP запитами
```
